# fakebiz

A backend software for a fake company that has an inventory system, employee records, tracks orders, and much more

#1 Clone the repository
#2 Open the cloned repository in terminal
#3 run "docker compose up" (make sure docker is running)
#4 Open your browser and go to localhost:8000/docs
#5 To exit press CTRL + C
#6 Run "docker compose down"
